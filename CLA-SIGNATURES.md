# Contributor License Agreement: signatures

Each line below records that a contributor agreed to the dictate Individual Contributor License Agreement (`CLA.md`)
in the version named in the line. How it works is described in Annex B of `CLA.md` and in `CONTRIBUTING.md`.

To agree, add one line for yourself at the end of the table, in a commit authored by you (the commit author must be
the person named in the line), as part of your first pull request or merge request, with this commit message:

```text
I agree to the dictate Individual Contributor License Agreement, version <version>
```

Columns: your full name; the account you submit from, with the host (for example `github.com/yourname`); the date of
the commit (YYYY-MM-DD); the version of `CLA.md` you agree to (its version line).

The maintainer, Daniel Kurdoghlian, holds the copyright in dictate and needs no line.
